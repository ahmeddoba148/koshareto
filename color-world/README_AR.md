# COLOR WORLD داخل كشريتو

المشروع داخل `color-world` في ريبو `ahmeddoba148/koshareto`، على فرع `codex/color-world-android`. مشروع كشريتو الأصلي لم يتغير.

## ما تم تنفيذه

- مشروع Godot 4.4.1 أصلي للموبايل، رأسي، دون HTML أو WebView.
- مولد محتوى ثابت ينتج 100 منطقة متصلة و1500 مستوى و1500 مجموعة طلاء و4500 نجمة كحد أقصى.
- مزج RGB بدقة 0.1% وبمجموع ثابت 100%، لون مباشر وتقييم OKLab عند المطابقة.
- التقدم والعملات والمتجر والمساعدات الثلاث والإعادة وتحسين اللون والطلاء.
- حفظ محلي بمعاملات ونسخة احتياطية واسترجاع، وإعادة بدء بتأكيد وضغط مطول.
- استكشاف العالم وكاميرات الطلاء وحركة العناصر، وموسيقى ومؤثرات مولدة.
- واجهات عربية وإنجليزية، إعدادات الصوت والاهتزاز والجودة، واحتفالات اكتمال المناطق والعالم.

## التحقق الفعلي

شغّل GitHub Actions محرك Godot الحقيقي. نجح 50,843 تحققًا، بما فيها الوصول إلى التطابق التام لكل المستويات، مسار التقدم 1–1500، جمع 4500 نجمة، منع تكرار المكافآت، والمساعدات واسترجاع الحفظ. تم تشغيل المشهد الأصلي والتقاط شاشات فعلية؛ أُصلحت أخطاء ظهرت في الحفظ وإغلاق الصوت وترتيب النصوص.

افتح workflow باسم **COLOR WORLD Android** في Actions. التشغيل الناجح ينتج:

- `COLOR-WORLD-APK`: ملف Android للتثبيت التجريبي.
- `COLOR-WORLD-validation`: نتائج الاختبارات وصور الواجهات.
- `COLOR-WORLD-Android-smoke`: صور ولوج اختبار التثبيت والتشغيل والاستئناف على محاكي Android.

يجب مراجعة حالة التشغيل المرتبطة بنفس commit؛ وجود الاختبارات وحده ليس نجاحًا لها.

## التشغيل من المصدر

ثبّت Godot 4.4.1 Standard وPython وNumPy وخط DejaVu Sans. من مجلد `color-world`:

```sh
python tools/prepare_assets.py
python tools/build.py --tests-only
```

ثم افتح `project.godot` واضغط F5. ملفات العالم والصوت والخط تُنتج قبل الاستيراد، ولا يحتاج الهاتف Python أو الإنترنت.

لتصدير Android، ثبّت قوالب Godot المطابقة وOpenJDK 17 وAndroid SDK واضبط مساراتها ثم:

```sh
python tools/build.py --platform android
```

الناتج `build/COLOR_WORLD.apk` بتوقيع Debug للتجربة. iOS يتطلب macOS وXcode وهوية Apple Team لصاحب اللعبة؛ لم تُنتج نسخة IPA متحققة.

## حدود النسخة

هذه نسخة تنفيذ قابلة للاختبار، **وليست اعتمادًا بأنها استوفت وثيقة الإنتاج بالكامل**. العالم مركّب إجرائيًا من مجسمات هندسية؛ لا يساوي ذلك اعتماد 100 منطقة بالجودة الفنية المطلوبة. الصوت مولد ويحتاج مراجعة سمعية. لم تُقَس الحرارة أو البطارية أو ثبات 60 FPS على هاتف فعلي، ولم تُعاير صعوبة الألوان مع لاعبين. اختبار المحاكي لا يحل محل هذه الاختبارات.
