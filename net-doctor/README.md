# Net Doctor

تطبيق أندرويد تجريبي لتشخيص تهنيج الراوتر والشبكة تلقائيًا.

## ما الذي يراقبه؟
- Gateway / الراوتر الأساسي (يتم اكتشافه تلقائيًا)
- Access Point الافتراضي: 192.168.1.2
- DVR الافتراضي: 192.168.1.18
- الإنترنت: 8.8.8.8
- DNS
- HTTP connectivity
- Wi‑Fi RSSI / frequency / channel / link speed عند سماح أندرويد بالصلاحيات

## اللوج
يسجل التطبيق Ping وPacket Loss وMin/Avg/Max وJitter وTimeouts وتوقيت بداية/نهاية الانقطاع، ويعطي تشخيصًا تلقائيًا للسبب الأقرب. يمكن نسخ اللوج كاملًا أو مشاركته كملف TXT.

## الخصوصية
كل البيانات محفوظة محليًا على الهاتف ولا يرسل التطبيق اللوج لأي سيرفر.

## APK
GitHub Actions يبني نسخة Debug APK تلقائيًا، وتظهر في Artifacts باسم `NetDoctor-APK`.
